# Gapla — iPhone, iPad va Mac

Gapla o'zbekcha ovozli yozish ilovasi. Gapla klaviaturasida tugmani bosib gapirasiz, matn o'zi yoziladi.

Bu repoda ilovaning iPhone va iPad kodi bor. Kod [OpenWhispr](https://github.com/OpenWhispr/openwhispr) mobil ilovasiga asoslangan va MIT litsenziyasi bilan tarqatiladi (`LICENSE`).

Kompyuter ilovasining Mac uchun kodi `kompyuter/` papkasida turadi. U o'z faylini alohida yig'adi (`.github/workflows/gapla-mac-dmg.yml`).

## Yig'ish

Ilovani GitHub'ning Mac serveri yig'adi (`.github/workflows/gapla-ios-ipa.yml`). Natija Actions sahifasida «gapla-ios-ipa» nomli fayl sifatida chiqadi. Bu imzosiz IPA, uni telefonga iloader yoki SideStore bepul Apple ID bilan o'rnatadi.

## Bu repo qanday yangilanadi

Bu repo — nusxa. Asl kod boshqa joyda turadi va bu yerga skript orqali qo'yiladi. Shuning uchun bu yerga qilingan o'zgarish keyingi yangilanishda o'chib ketadi.

Kodda kalit ham, parol ham yo'q. Diktovka kalitini foydalanuvchi ilovaning o'zida kiritadi.
