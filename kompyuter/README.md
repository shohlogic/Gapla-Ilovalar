# Gapla — kompyuter ilovasi (Mac)

Gapla o'zbekcha ovozli yozish ilovasi. Tugmani bosib gapirasiz, matn siz yozib turgan joyga o'zi tushadi.

Bu papkada ilovaning kompyuter kodi bor. Kod [OpenWhispr](https://github.com/OpenWhispr/openwhispr) ilovasiga asoslangan va MIT litsenziyasi bilan tarqatiladi (`LICENSE`).

## Yig'ish

Ilovani GitHub'ning Mac serverlari yig'adi (`.github/workflows/gapla-mac-dmg.yml`). Natija Actions sahifasida ikki fayl bo'lib chiqadi: `gapla-mac-arm64` (Apple M1, M2, M3, M4 va keyingi Mac'lar uchun) va `gapla-mac-x64` (Intel protsessorli Mac'lar uchun). Ilova Apple tomonidan imzolanmagan, shuning uchun birinchi ochilishda Mac ogohlantirish beradi.

## Bu papka qanday yangilanadi

Bu papka — nusxa. Asl kod boshqa joyda turadi va bu yerga skript orqali qo'yiladi. Shuning uchun bu yerga qilingan o'zgarish keyingi yangilanishda o'chib ketadi.

Kodda kalit ham, parol ham yo'q. Diktovka kalitini foydalanuvchi ilovaning o'zida kiritadi.
